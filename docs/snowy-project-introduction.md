# Snowy：面向高中生的可信 AI 学习与科学推演项目

> Snowy 是一个面向高中生的 Web 端 AI 学习项目，试图把“问问题、理解推导、调参数和复盘记录”连接成一条学习路径。它不只追求给出答案，而是让学生看到结论为什么成立，以及变量变化后模型会如何变化。

## 一句话介绍

高中学习里，真正浪费时间的往往不是“完全找不到答案”，而是答案难判断、过程看不懂、公式和真实题境对不上。Snowy 希望把 AI 从“会聊天的搜索框”推进到“可推演、可复盘的学习工具”：它可以围绕高中问题组织回答、公式、推导步骤、易错点和可交互模型，让学生更容易把知识点转化为可迁移的理解。

如果说普通搜索解决的是“我能不能找到资料”，Snowy 更关注的是“我能不能真正理解这道题、这个模型和这个知识点”。

## 为什么需要 Snowy

高中生在使用资料和 AI 工具学习时，常见问题集中在三个断点。

**第一，答案容易得到，但质量难判断。**
学生即使通过搜索或 AI 工具拿到解释，也不一定知道它是否对应当前课程范围、题目条件和高中阶段的表达方式。

**第二，结论容易得到，过程不容易理解。**
许多工具可以快速给出结论，但不会按高中生能理解的方式展开条件、公式、题型和易错点。学生看似“问到了答案”，实际上没有建立可迁移的解题模型。

**第三，抽象过程不可见。**
物理运动、受力分析、生物过程和实验变量，很难只靠静态文字建立直觉。Snowy 尝试把这些过程转化为图、参数和可继续追问的交互链路。

## Snowy 能做什么

### 1. 知识点直答：把答案组织成学习材料

Snowy 的问答链路围绕“答案 + 解释 + 后续学习”组织，而不是只返回一段文本。当前默认运行链路是 LLM 直答，并补充知识点标签、公式卡、易错点、相关问题和下一步建议等结构化结果。系统会使用 runtime grounding 说明回答来源于用户题干与高中阶段通用知识；真实课程资料索引和可核验引用属于后续可接入能力。

这件事的重点不是让 AI “说得更像人”，而是把回答拆成学生可以继续学习的材料：先看结论，再看公式、条件、易错点和下一步推演入口。对尚未接入真实资料索引的场景，文档不把 runtime grounding 写成课本或题库引用。

### 2. 物理 / 3D 推演：把公式和变量关系变成可观察模型

面对平抛运动、牛顿第二定律、受力分析、弹簧振子等典型模型，Snowy 会抽取题干条件，给出推导说明，并把参数、公式和场景组织成可视化模型。学生可以调整初速度、高度、角度、质量等参数，观察轨迹、受力和关键结果如何变化。

当前技术路线更强调由本地物理 / 渲染引擎承载确定性仿真，LLM 负责题意解析、参数抽取和结构化 scene_spec。这比完全依赖模型生成代码更适合教育场景中的稳定演示。

### 3. 生物建模：拆解概念、过程和实验变量

生物学习经常难在过程链条和实验变量。Snowy 支持围绕光合作用、呼吸作用、遗传、实验设计等内容做概念识别、关系抽取、过程拆解和变量影响分析。它可以把一段题干拆成核心概念、过程阶段、自变量、因变量、控制变量和常见误区。

这类能力适合处理“看起来像背诵，实际考理解”的题目。

### 4. 学习档案：把一次提问变成可回看的学习资产

登录后，Snowy 可以把历史提问、收藏、答案归档和模型包沉淀到学习档案里。学生可以回到之前的问题，继续追问、复盘易错点，或者重新打开某个模型包调整参数。

### 5. LLM 调用监控：让模型链路可观察

对项目维护者和教研验证者来说，Snowy 提供 LLM 调用监控、Prompt Profile、模型配置和调用记录等能力。它关注的不只是前台体验，也包括模型调用耗时、成功率、Token 使用、错误诊断和配置状态。

## 典型使用场景

### 场景一：学生查概念

学生输入“牛顿第二定律在斜面题中怎么用”。Snowy 返回简洁解释、公式含义、适用条件、易错点和后续学习入口。当前默认链路使用 LLM 直答和 runtime grounding；若未来接入课程资料索引，系统可以进一步展示可核验资料摘录。

### 场景二：学生看推导

学生输入“平抛运动最大水平位移怎么推导”。Snowy 识别模型条件，列出公式、推导步骤和变量关系，并提示哪些条件变化会影响结果。

### 场景三：学生调参数理解变量

学生打开平抛运动模型，调整初速度和高度。画布里的轨迹、飞行时间和水平位移同步变化，学生能直观看到变量如何影响结果。

### 场景四：学生拆生物实验题

学生输入“光照强度变化如何影响有机物积累”。Snowy 拆解光合作用、呼吸作用、限制因素、自变量、因变量和控制变量，并给出实验设计里的易错点。

### 场景五：教师或教研验证内容质量

教师可以检查 Snowy 的回答是否贴合高中课程范围、解释是否适合学生理解、是否清楚标注能力边界。教研人员也可以通过后台监控观察模型调用耗时、错误和配置状态。

## 技术亮点

Snowy 的技术亮点不在于“接入了一个大模型”，而在于围绕教育场景建立了一套可追溯、可约束、可渲染、可观察的 AI 学习系统。

### 1. 知识点直答：把生成结果变成可学习结构

当前 Snowy 默认问答链路不是“资料召回后再生成”，而是通过统一 Prompt Catalog 约束 LLM 直接回答，并将结果整理为结论、关键点、必要步骤、易错点、公式卡、相关问题和 runtime grounding。OpenSearch、Embedding 和资料索引代码保留为后续可接入的检索能力，但不在当前默认运行链路中声称“资料召回后再回答”。

### 2. Agent 编排：把聊天拆成学习任务流

Snowy 使用 Agent 编排识别用户意图，并将问题路由到不同工具链：知识点直答、物理推演、生物建模、学习档案等。它不是单轮聊天，而是把学习请求拆成意图识别、推理、结构化输出、可视化渲染和后续建议等步骤。

### 3. 结构化输出协议：让 AI 结果可被产品稳定消费

项目强调协议优先：答案、参考信息、公式卡、推导步骤、Render Manifest、关系图、变量分析等尽量以结构化结果输出。这样前端不是展示一段不可控 Markdown，而是能把 AI 结果拆成参考信息、可折叠公式、可调参数和可复用模型包。

### 4. 本地引擎与沙箱渲染：让演示可交互但不失控

物理推演优先由本地物理 / 渲染引擎承载，确保仿真行为更稳定。生物过程等非物理演示可以通过受限 HTML / Canvas 输出，在 iframe sandbox 中运行，并配合 API 白名单和危险 API 限制降低风险。最终学生看到的是可交互模型，系统保留的是可控制的执行边界。

### 5. 多模型路由：在质量、稳定性和成本之间做工程平衡

Snowy 支持按配置声明多个 OpenAI-compatible 模型供应商，并按顺序调用、重试和失败切换。这样可以在质量、稳定性和成本之间做工程平衡：普通问答追求响应速度，复杂推演追求推理质量，后台监控追踪耗时、Token 和错误率。

### 6. LLM 可观测：把模型调用从黑盒变成可排障系统

AI 调用监控页展示调用总量、平均耗时、成功率、Token 消耗、Prompt Profile、Provider 状态和调用记录。对研发、运营和教研来说，这意味着可以排查“哪个模型慢、哪个链路失败、哪个 Prompt 需要优化”，而不是只能凭感觉调参。

### 7. 前后端分离与学科扩展：为更多科学建模场景预留接口

Snowy 采用 Go / Gin 后端、Agent 编排、MySQL / Redis、OpenAI-compatible LLM Provider、Next.js + TypeScript 前端的 monorepo 架构，并保留 OpenSearch、Embedding 等可选检索适配能力。物理、生物、化学等方向可以作为领域工具和渲染协议逐步扩展，而不是在一个聊天页面里堆功能。

## 技术可信度

Snowy 的技术路线不是简单把大模型接到聊天框上，而是围绕教育场景做了多层约束：知识回答层通过 Prompt Catalog、知识标签、公式卡、易错点和 runtime grounding 约束输出；Agent 编排层负责识别意图、选择知识点直答、物理建模或生物建模等工具，并组织结构化输出；多模型路由层用于在不同模型供应商之间做调用顺序、重试和失败切换；渲染层通过本地引擎或受限沙箱展示可交互结果，降低动态演示的安全风险；可观测层记录模型调用、耗时、错误和 Provider 状态，方便后续优化质量与稳定性。

项目采用 Go / Gin 后端、MySQL、Redis、OpenAI-compatible LLM Provider、Next.js + TypeScript 前端，并保留 OpenSearch、Prometheus、Grafana 等可扩展适配。它服务于一个明确目标：让 AI 学习产品不仅“能生成”，还要尽可能“可追溯、可观察、可扩展”。

## 当前状态与适合关注的人

Snowy 当前更适合作为一个可运行的 AI 学习产品原型和工程验证项目，而不是已经大规模商业化运营的成熟产品。项目已经具备首页、提问、推演、学习档案、AI 调用监控等主要页面和后端链路；课程资料索引、真实引用质量、复杂化学建模、教师后台和规模化运营仍需要继续补充数据、测试和产品验证。

如果你是学生，Snowy 值得关注的点是：它能不能帮你更快看懂一道题，而不是只给一个答案。

如果你是老师或教研，Snowy 值得关注的点是：它是否能把 AI 回答约束在课程范围、教学表达和可核验能力边界之内。

如果你是研发或产品同学，Snowy 值得关注的点是：它把 LLM 直答、Agent、可交互建模、可观测和学习闭环放进了一个相对完整的教育产品原型里，并为后续资料索引与检索增强预留接口。
