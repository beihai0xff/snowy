# Snowy v4 重构蓝图：面向高中生的 AI 科学任务舱

## 1. 背景诊断

Snowy 现有 MVP/v2 已具备三条能力线：AIGC 知识检索、物理/3D 场景建模、生物过程建模。但高中生真实学习不是按“搜索、物理、生物”模块切换，而是围绕一个问题逐步完成：找证据、建模型、调参数、解释原因、做迁移练习。因此 v4 将产品从“多模块学习平台”升级为 **AI Science Mission Cockpit（AI 科学任务舱）**。

### 1.1 核心痛点
- **可信问题**：学生需要知道 AI 结论来自课本、考纲、讲义还是题库，避免把生成内容当标准答案。
- **理解问题**：物理公式、生物过程和题目条件之间缺少可视化桥梁。
- **动机问题**：单纯问答和静态图谱难以维持高中生探索动机。
- **迁移问题**：会看答案不等于会做题，需要即时挑战、错误解释与变式训练。

### 1.2 游戏领域启发
- **任务目标比积分更重要**：每次建模都给出“命中目标区 / 解释平台期 / 修正变量控制”等可完成目标。
- **即时反馈降低认知负荷**：参数滑动后同步改变轨迹、曲线、公式项和一句话结论。
- **失败应转化为学习线索**：失败提示需指向方向、单位、变量控制、条件假设或概念混淆。
- **关卡递进促进迁移**：演示关 → 单变量挑战 → 多变量挑战 → 变式题。

### 1.3 AI 领域启发
- **证据先于生成**：RAG 引用、知识标签和置信度作为模型生成的前置上下文。
- **结构化模型包优先**：LLM 不直接产出任意代码，而是生成 LearningModelSpec、SimulationSpec、VisualizationSpec、InteractionPlan、AssessmentTask。
- **本地重算 + 再推理分层**：数值变化本地重算；结构、假设、解释变化触发 LLM 再推理。
- **校验闭环**：Schema 校验、领域规则校验、安全校验、置信度与再生成建议并列展示。

## 2. v4 产品定位

> Snowy v4 是面向高中生的 AIGC 知识检索、物理仿真与生物可视化统一建模工具，以可信证据为燃料，以 AI 生成式模型包为核心，以游戏化任务和实时可视化为学习体验。

## 3. v4 信息架构

| 页面 | v4 定位 | 关键体验 |
|---|---|---|
| 首页 / 指挥舱 | AI 科学任务入口 | 搜索即建模、能力雷达、任务卡、学习链路 |
| 知识星图 | 证据型学习搜索 | 引用、公式卡、易错点、题型映射、建模跳转 |
| 科学建模舱 | 统一三栏工作台 | 左证据、中画布、右参数/AI 教练/微练习 |
| 任务档案 | 学习闭环 | 历史、收藏、任务进度、下一步建议 |
| AI 监控 | 可信工程面板 | 模型调用、延迟、Prompt Profile、失败诊断 |

## 4. 统一学习链路

```text
问题输入 → 证据检索 → 领域解析 → 生成式模型包 → 交互仿真/可视化 → AI 教练反馈 → 微练习/反思 → 学习档案
```

## 5. 前端重构要点

### 5.1 视觉系统
- 深空科技底色：深蓝/靛紫/青色径向光斑，突出“实验室/任务舱”氛围。
- 玻璃拟态卡片：半透明、模糊、细边框、内发光，适配高中生喜欢的未来感。
- 动态网格和扫描线：营造数据流、仿真舱、AI 引擎正在工作的感受。
- 高亮色体系：Cyan=可信证据，Green=完成/命中，Amber=挑战/警告，Pink=错误/再推理。

### 5.2 首页升级
- 一屏说明“Snowy V4 AI 科学任务舱”。
- 搜索框直接承载“问问题 / 输入题目 / 发起建模”。
- 三张核心能力卡：知识星图、物理仿真、生物可视化。
- 学习流程以任务链展示，降低学生进入门槛。
- 推荐内容改为“任务卡”，更接近游戏关卡入口。

### 5.3 科学建模舱升级
- Header 展示当前阶段：检索证据、AI 推理、领域校验、通用渲染。
- 左栏“问题与证据”展示引用与知识标签。
- 中栏“模型画布”展示物理轨迹/向量/曲线或生物图谱/阶段/变量影响。
- 右栏“AI 教练”展示参数滑杆、生成式挑战、微练习和校验报告。
- 每个变量标记“本地重算”或“需再推理”。

## 7. 验收标准

- 首页、导航、建模页、搜索页形成统一深色科技视觉系统。
- 首页明确传达“面向高中生的 AIGC 知识检索、物理仿真、生物可视化统一建模工具”。
- 建模页保留并强化 v4 三栏工作台：证据、模型画布、AI 教练。
- 页面体现游戏化学习：任务、挑战、即时反馈、微练习、再推理。
- 前端通过 `npm run lint` 与 `npm run build`。
