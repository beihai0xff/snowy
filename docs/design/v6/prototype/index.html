Snowy v6 设计原型集

本目录是 Snowy 前端 UI 重设计稿（v6 草案）的可交互静态原型。设计哲学：克制 · 现代 · 学习工具优先。 所有页面均为纯 HTML/CSS，使用浏览器直接打开即可预览。建议从「首页」开始 review。

ℹ︎
如何 review
1. 先看 首页 与 README.md 校准方向； 2. 每页右下角有「📱 移动预览」按钮，一键切到 414 宽视图，测响应式； 3. 顶栏右侧「☾ 深色」按钮切换深色主题，验证暗色对比度； 4. 反馈意见可以贴页面 + 区块名（如「首页 · 今日可以试试」），方便迭代。
