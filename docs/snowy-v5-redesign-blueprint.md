# Snowy v5 重构蓝图：面向高中生的 AI 科学任务舱

## 1. 核心设计目标

- **重构 API 接入模块**：以 openai API （可参考 https://github.com/openai/openai-python，优先选择 golang 的替代版本，或者自己构建），兼容不同大模型厂商模型，提供统一的调用接口和错误处理机制。提供统一配置文件，支持模型切换和参数调整，用户可以配置多组模型及其优先级，以便于兜底。每个模型包含以下配置项
  - 模型厂商
  - base URL
  - API Key
  - 模型名称
  - 请求参数（温度、max tokens 等）
  - 错误重试次数和间隔
- **实现用户登陆与收藏功能**：用户可以通邮箱注册和登录。登录后可以收藏问题、证据、模型配置等内容，形成个人学习档案。支持用户信息和收藏数据的持久化存储（可以考虑使用 MySQL）。
  - 同时持久化每个问题的答案与建模代码
  - 每个用户对不同答案或建模的 like、dislike 都持久化记录下来，其他用户客户端展示时可以看到点赞数和点踩数，甚至可以看到点赞和点踩的用户列表（如果用户隐私设置允许的话）。这样可以形成社区反馈机制，帮助用户判断答案和建模的质量。
  - 用户可以在个人档案中查看自己的历史问题、收藏内容、点赞记录等，形成完整的学习轨迹。
- **增强 AI 监控模块**：以用户粒度记录大模型调用明细，监控面板展示调用频次、延迟分布、错误率、Prompt Profile（输入输出示例）等指标，支持按时间、用户、模型等维度过滤和分析。提供异常诊断工具，帮助开发者快速定位和解决问题。同时将监控数据持久化（可以考虑落MySQL），即使容器重启支持后续的模型优化和用户行为分析。
